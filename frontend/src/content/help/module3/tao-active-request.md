Bước 3 trong luồng — đăng ký khoá học cho UID khách hàng, hệ thống xuất ra Course Code dùng để đối chiếu hoá đơn.

## Các bước

1. Mở PR đã thu tiền → bấm **Tạo Active Request mới** (hoặc thao tác từ danh sách Kích hoạt khóa học).
2. Liên kết Payment Request tương ứng (khuyến nghị, giúp đối soát doanh thu chính xác).
3. Điền UID, gói học, số buổi.
4. Chọn **Kích hoạt ngay** hoặc **Chưa kích hoạt** (giữ hold, ghi lý do) tuỳ tình trạng khách.
5. Xác nhận — hệ thống tự sinh Course Code.
